# Security Policy

## Supported scope

Security reports are welcome for the current `main` branch of this project.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Contact the repository owner privately through GitHub with:

- a concise description of the issue;
- steps needed to reproduce it;
- affected files or components, if known; and
- any suggested mitigation.

Please allow reasonable time for investigation before public disclosure.

## Safety notes

This tool is intended for diagnostics on networks you control or are authorized to troubleshoot. Do not commit credentials, tokens, private network inventories, or other sensitive information.
